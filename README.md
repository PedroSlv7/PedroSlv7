## 🚀 Projeto em Destaque

### 🏫 LabReserve — Sistema de Agendamento de Laboratórios

Sistema desenvolvido para organizar e gerenciar reservas de laboratórios acadêmicos, ajudando a evitar conflitos de horários e facilitando o gerenciamento das reservas.

### ⚡ Tecnologias utilizadas

- Java 17
- JavaFX
- CSS3

### 🔥 Funcionalidades

- Cadastro de usuários e laboratórios
- Gerenciamento de reservas
- Validação de conflitos de horários
- Controle de status das reservas
- Painel diário de reservas
